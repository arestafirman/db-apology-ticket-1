Entry for **The Production Database Apology** on Make.fun — write the perfect
apology for deleting the production database, in one line.

## The entry

> I deleted the production database. I have filed a ticket to restore it — ticket number 1, because the ticketing system was in the database too.

## Why it's funny

Two beats. **Beat 1** is the confession: the production database is gone,
stated flat, no excuses. **Beat 2** is the escalation: the ticket filed to
restore it is ticket number 1 — because the ticketing system itself was in
the database too. The system that tracks the disaster was a victim of the
disaster, so there is no ticket history, no ticket 0, nothing to restore
from. The number is the punchline.

## Run

```sh
node main.ts
```

Requires Node 22+. No dependencies, no network calls — it writes the entry
to `output/entry.txt` (one line, no trailing newline).
